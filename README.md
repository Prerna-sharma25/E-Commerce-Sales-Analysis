# E-Commerce Sales Analysis

## Project Overview

This project focuses on analyzing e-commerce sales data to understand sales performance, product performance, and sales trends.

Python was used for basic data analysis and Power BI was used to create an interactive dashboard.

## Tools Used

- Python
- Pandas
- Power BI

## Analysis

- Total Sales
- Gross Profit
- Profit Margin
- Total Orders
- Units Sold
- Sales by Category
- Sales by Platform
- Monthly Sales and Profit Trends
- Top Products by Sales
- Country-wise Performance

## Dashboard

An interactive Power BI dashboard was created to visualize the sales data and identify important business trends.

## Dataset

The dataset contains e-commerce sales information including products, orders, sales, profit, platforms, dates, and countries.
